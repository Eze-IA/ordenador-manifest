# Privacy Policy for Manifest - Intelligent File Sorter

**Last updated: July 2026**

Manifest ("the Extension") is a developer tool designed to sequence and sort logical deployment files locally in the browser.

### 1. Information Collection and Use
The Extension **does not collect, store, transmit, or share** any personal data, browsing history, or user information. All operations, text sorting, and file processing are executed 100% locally on the user's machine within the extension's execution sandbox.

### 2. Third-Party Services
The Extension does not integrate with any third-party services, analytics, or external tracking APIs.

### 3. Data Security
Since no data is collected or transmitted over the internet, your infrastructure configurations, manifests, and database scripts remain entirely secure and private within your local environment.

### 4. Contact
If you have any questions about this Privacy Policy, you can open an issue directly in this GitHub repository.
